# Veriquery 项目改动与评测台账

项目定位是器件规格书问答。开源基线为 FinalSunFlower/Veriquery，评测题目与方法参考 palginpav/datasheet-rag。此处保存工程改动、实测结果和证据位置，供复盘与简历核对。项目归属为个人项目，实习岗位、职责、候选人亲自实施的改动和演示范围需要按实际情况确认。

## 文档问答的部署选择

按项目负责人的显存预算，文档问答选用 Qwen3.5-0.8B，Xinference UID 为 `qwen3.5`，后续优化以该模型为基线。新器件对照中，含嵌入和重排服务的整卡显存快照分别为 7474 MiB（0.8B）和 15060 MiB（4B）。峰值需求仍需在目标机器的实际工作负载下测量。[部署配置](AUTODL_SETUP.md) · [模型效果与资源对照](UNSEEN_MODEL_API_RESULTS.md)

## 后续复用

- 优先保留每轮的题目版本、样本分母、固定语料与模型、开关、原文页码、原始 API 输出和判定口径。每个指标应能定位到一份实际运行和具体失败用例。
- 33 题已用于发现和修复问题，适合写为固定开发回归集的结果。独立新题、完整语料、重复运行和实际上线需要有各自的记录后才能引用相应结果。
- 各报告链接到已归档的选页哈希、逐题评分或原始回放。工作区的 `data/eval/` 默认由 Git 忽略，发布时按文件选取证据。九层审计的会话编号可串起召回候选、实际输入、回答与引用。[九层证据入口](QA_NINE_STAGE_TRACE.md)
