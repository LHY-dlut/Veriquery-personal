## n06 · 已生成的答案能否到达用户

取以前同一份 402-token 原文，旧清洗输出 333 字符，最后一行停在“计算端点偏离典型值（TYP）的最大允许偏差”。新清洗输出 618 字符，结尾原样保留“振荡频率的满量程范围是 0.4 MHz”和“端点偏离 TYP 的最大允许偏差是 200 kHz”，引用标记亦保留。模型客户端和 API 路由复用同一段按行去重逻辑，只折叠相邻且完全相同的行，保留短数值、小数、引用和末尾结论。预算改为读取 `LLM_MAX_TOKENS`，常规默认仍为 256。转录任务沿用独立预算。

实机上，只修清洗时，256 组的三次首稿都用满预算，一份由引用修复补全；512 组三份最终答复都正确。全量修复后的 512 组有一份凭空引入“5%”的偏差，尽管实际入模振荡频率行仍是 2200 / 2400 / 2600 kHz。两次 512 组的 n06 输入提示摘要相同。由此可以确认清洗保真和更长预算的实际收益，也可以看到相同证据下的生成波动。[清洗实现](../core/llm_client.py) · [路由处理](../api/routers/chat.py) · [原始 402-token 记录](../data/eval/formula-ingest-ab/results/budget-check.jsonl)

## n10 · 三条证据能否共同进入模型

修前 3 个会话均未把完整理想步长公式和独立反馈表行送入模型。修后两个预算共 6 个会话，逐个检查下游首稿请求的 `messages`，均具备以下两块证据，单次上下文共 4007 字符。

| 输入证据 | 实际送入内容 |
|---|---|
| MCP4725，`c06748dc_p2_c8`，535 字符 | 式 4-1 的 `VREF / 2^n` 及其同块 Where 定义，包括 VREF=VDD 和 MCP4725 的 n=12。 |
| TPS63020，`386a2473_p1_tbl7` | 紧挨数据行的表头 `TEST CONDITIONS / MIN / TYP / MAX / UNIT`；原行包含 `TPS63020 feedback voltage`、`PS/SYNC = V_IN`、`495 / 500 / 505 / mV`。 |

保留检索及重排顺序，继续使用 4200 字符总预算。上下文组装按文档数分配槽位，允许完整的小公式块使用该文档的预算份额，并在所有文档已有证据后继续利用尾部空间容纳独立表行。[上下文组装](../agents/workflow_nodes.py)

512 组第 2 次是最有辨别力的失败。会话 `d799db60-4406-4a05-8ec9-eb859173175e` 明确给出 495/505 mV、1 mV 步长以及 10 mV / 1 mV = 10 步。最终引用 [1] 对应正确的 MCP 公式，但 [2] 指向 `386a2473_p1_c2`，内容包括 TPS63021 的输出、PS/SYNC=GND 和振荡频率，缺少 495/505 mV。正确带表头行在入模材料 [8]。因此这次数字正确、严格未通过。另外两次 512 样本均算错步长，一次直接把 TPS 输出电压 5.5 V、1.2 V 当作 MCP 的 DAC 两端。后续应优先验证引用片段是否同时含目标器件、工况、字段和数值，并将跨器件算式的每个操作数绑定到对应证据。[n10 各次最终正文](evidence/output-context/answers.md#n10)

## 剩余四题的首要错因

| 题 | 修后 512 样本中的证据 | 后续验收重点 |
|---|---|---|
| n02 · 进制与电压 | 三次最终均拒答。第 2 次首稿已得 1 mV，却把 0x600 解成 24576，算出 24.576 V。 | 正确十六进制展开得到 1536，再乘步长；分别核验可答部分和引用修复的结果。 |
| n03 · 有符号 DNL | 第 2 次用两条原公式得到正的 0.25 LSB。第 3 次中间算出 0.25，结尾却写 1.25 小于 1，并改答 −0.25 LSB。 | 核验最终符号与相邻级差减理想步长的符号一致。 |
| n04 · 理想电压与 INL | 第 2 次报告 0.24414 mV 和 4086.8 LSB，推导中把步长取作 1/4096，漏乘 4.096 V。公式和定义已入模。 | 先核对带单位的 1 mV 步长，再核对 1000 mV 和 −1.5 LSB。 |
| n07 · 理论值与推荐值 | 第 2 次完整给出 1008 kΩ、1 MΩ，并分别引用式 (3) 与推荐表。第 1 次两个数也对，但把推荐电阻归给电气特性表。第 3 次把 1008 写成 mV，最终又写成 mΩ。 | 分别检查理论电阻和推荐表项的量纲、工况与引用。 |
