# 文档问答的分层评测

以 VQ-18 的 60 份真实 API 答复及其下游回执为样本。两版各 15 题、每题两次。此次离线重读历史记录，新建的是事后证据标注和评分明细。用手册事实核对各阶段时，把文档、页码与原文关联起来。资料原页到上传选页的对应关系见 VQ-17 和 VQ-18。

| 观察点 | 改前 | 改后 | 口径 |
|---|---:|---:|---|
| 请求范围及返回证据的文档归属 | 30/30 | 30/30 | 每个请求的 document_ids 等于预期文档集合，返回候选和上下文的 document_id 均在范围内。系列型号另由同段公式定义确认 |
| 重排后 Hit@8 | 30/30 | 30/30 | 前八个返回候选中至少有一个命中已标事实 |
| 重排后关键事实 Recall@8 | 68/68 | 68/68 | 每道题需要一至五项证据，各题共 34 项需求，重复两轮。检索文本在正确文档页包含该事实的全部标注引文 |
| 已召回事实保留到最终上下文 | 68/68 | 68/68 | 在最终编号正文按段重新匹配，分母为前八候选已经命中的事实数。两版均有 30/30 份上下文含齐本题标注事实 |
| 指定原文字段的取值（下表抽查） | 14/14 | 13/14 | 只核对三题的指定读数。漏报计错，数值单位、行和列含义均需对应。推导、额外陈述和引用另按整题口径评 |
| 最终严格通过 | 11/30 | 25/30 | 沿用逐份严格评分。改后程序计算路径 24/24；普通 0.8B 生成路径 1/6 |

改后把同一份排序的截点改为 K=1，第一名命中 40/68 项事实，至少命中一项的请求为 22/30。多块证据对本批问题有补充作用。这个对照只变动评分时的截点，没有重新生成答案。

**解析准确率仍缺全量分母。** 本轮没有对所有题目的源 PDF、MinerU 输出和落盘文本做独立逐项盲标。既有对照证实，通过公式入库修复，同一解析结构的七个目标公式或定义块在适配器正文中从 0/7 变为 7/7，新索引保留了 7/7。这能定位入库阶段丢块，无法据此估计 MinerU 对其他公式、数字或表格的解析准确率。[公式与入库实验](FORMULA_INGEST_AB_RESULTS.md)

**最初召回与重排贡献需要分开采集。** 上表使用普通 API trace 中已经重排的返回候选。这 60 次会话缺少三路原始候选及 RRF 全排名，无法从中计算重排带来的增益。早先六个独立会话保存了逐路原始候选、融合与重排，可用于个案复盘。[九层溯源](QA_NINE_STAGE_TRACE.md)

## 字段抽查

以下计数是对用户可见答复的逐字段核对。证据字段和算出的答案分开记。编号和重复序号可在明细及原始包中定位。

| 题目 | 每次核对的字段 | 改前第 1、2 次 | 改后第 1、2 次 |
|---|---|---|---|
| n06 | 振荡频率 MIN 2200、TYP 2400、MAX 2600 kHz | 3/3、3/3 | 3/3、3/3 |
| n07 | 公式代入的标称反馈电压 500 mV；目标 3.3 V、R2 为 180 kΩ 的推荐 R1 为 1 MΩ | 2/2、2/2 | 2/2、1/2。第二份没有给出推荐电阻 |
| n10 | TPS63020 在 PS/SYNC=VIN 下反馈电压的两个端点 MIN 495、MAX 505 mV | 2/2、2/2 | 2/2、2/2 |

n06 改后第 2 次的会话为 `5c2fd913-0b8e-4085-a736-5e2b5d63bc3f`。原行已进入第一轮模型消息，最终答复也标明了三个正确读数，却用 MAX 减 MIN 回答“单侧最大偏差”，将 0.2 MHz 写成 0.4 MHz。n07 改后第 1 次选对了标称电压和推荐电阻，但把按电阻公式算出的 1008 kΩ 写成 1008 mV。两者都说明要继续检查运算对象和量纲。[逐份最终答复与原评分](evidence/typed-transfer/answers.md)

## 复现与适用范围

从项目根目录运行以下命令。输出包含每个会话、每项事实第一次命中的排名、最终上下文的片段 ID、实际回答路径和下游调用次数。

```sh
python eval/replay_evidence_stages.py docs/evidence/typed-transfer/evidence.zip docs/evidence/typed-transfer/stage-gold.json --k 8
```

每项证据按文档、选页、同一段内的原文匹配，忽略空白并保留大小写。生成路径还检查最终上下文是否出现在第一笔真实模型请求中；程序路径按实际供程序使用的上下文计。程序命中、LLM 生成和后续引用修复可按回执区分，此链路已经移除旧 Resolver。

标注是在知道这批案例后整理的，只覆盖冻结问题所需的特定关系和行，不能衡量全文解析、库外新问题的召回或每个断言的忠实度。下轮应在看到系统答复前先冻结原页、表头、工况、值、公式与可接受的替代证据，并同步保存重排前后候选。[事实与题目映射](evidence/typed-transfer/stage-gold.json) · [逐会话机器明细](evidence/typed-transfer/stages.json) · [原始归档](evidence/typed-transfer/evidence.zip)
