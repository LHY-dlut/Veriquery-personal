# 冻结版本的独立器件问答评测

这轮检查局部规则能否迁移到之前未参与规则开发的器件，以及 LLM 在给足原文时能答到什么程度。冻结上一轮应用源码 `96103ff122f210ef392c26c9d59d9d161776bcd5e891d6fab93855cbee7ed0f1`。测试题、答案要求、厂商原页与题单哈希在第一次发出问答前固定。

选用 NXP LM75B（Rev. 6.1 原第 1、8、9 页）和 Maxim MAX30205（Rev. 0 原第 1、2、11、12 页）。两款器件均未用于此前规则调试，MAX30205 与历史 ADI 运放测试分属不同器件系列。原拟选 STTS751，PDF 下载失败后在首个问答前更换器件并冻结新题单。实际范围为同一大类的两个温度传感器与七个选页。 [NXP 规格书](https://www.nxp.com/docs/en/data-sheet/LM75B.pdf) · [Maxim 规格书](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX30205.pdf)

11 题包括 9 道可答题和 2 道应拒答题。可答题包含 2 道跨器件比较，另有寄存器解释、指定工况、温区表行与绝对额定值等题。评价按原文核对，要求数值、单位、条件、最终结论和引用相符。比较题要求两个器件各自的依据。分别检查入库文本、检索返回、实际入模内容与最终答案。两条证据分在实际收到的不同模型调用里时，单独标记是否存在联合推理的机会。

- 通用 RAG 和当前配置使用同一套 MinerU Advanced 索引副本、bge-m3、bge-reranker-v2-m3、Qwen3.5-0.8B，以及同一聊天 HTTP 接口。两组都保留引用检查与修复。通用组关闭精确表行优先、按器件比较、原文核验、多工况核验和指定增益核验，当前组打开这些开关。对照衡量开关组合的整体效果。
- 对 9 道可答题，将人工从厂商页核对的短证据送给同一个 LLM 的现有生成方法，观察获得充足证据后的答复。该诊断跳过 PDF 解析、检索和 HTTP 引用修复，单独计分。

## 实测结果

两份 PDF 均以 Advanced 就绪。LM75B 为 50 个检索块，MAX30205 为 49 个检索块。最终获得 22 条真实 HTTP 响应和 9 条人工短证据诊断响应。每组每道题调用一次。

| 指标 | 通用 RAG | 当前配置 |
| --- | ---: | ---: |
| 可答题完全正确且引用支持 | 1/9 | 1/9 |
| 应拒题正确拒答 | 2/2 | 2/2 |
| 合计达标 | 3/11 | 3/11 |
| 可答题的完整证据在索引中 | 9/9 | 9/9 |
| 可答题的完整证据进入召回候选 | 7/9 | 7/9 |
| 可答题的完整证据出现在实际模型输入中，按调用合计 | 6/9 | 6/9 |
| 有生成调用记录的题数 | 11/11 | 11/11 |

完整覆盖按事实和工况核对，单纯出现数字不计入。当前组在 h07 把两个器件的范围交给了两次独立调用，合计覆盖两项，但没有一次调用同时看到两者。9 道非跨器件题的入模上下文字节相同。h04、h06 在相同上下文下出现了不同错误，本次单次生成的波动不构成开关收益。两道拒答题按未给出虚构的 SPI 模式或 USB 长度计分，两组对 I²C 的措辞和格式仍有瑕疵。 [逐题评分](../data/eval/heldout/results/manual-review.json) · [通用 RAG 原始响应](../data/eval/heldout/results/plain.jsonl) · [当前配置原始响应](../data/eval/heldout/results/current.jsonl)

## 失败在哪一环

| 题 | 原文到答案的断点 |
| --- | --- |
| h02，LM75B 故障队列 | 原第 8 页的 `10 → 4` 在召回第 1 位 `25567d75_p2_tbl19`，答案也给了 4。原第 1 页“连续故障次数”的定义在召回第 10 位 `25567d75_p1_c3`，被上下文截掉。两组均未解释队列计数对象。 |
| h03，LM75B 温度寄存器 | 原第 9 页 `25567d75_p3_c13` 排在第 1 位，并在两组实际上下文中保留 16 位总线读宽和 11 位有效数据。模型仍答应读取 11 位。给人工短证据后答对。 |
| h04，MAX30205 温区误差 | 原第 2 页的 37–39 °C 和 41–45 °C 两条误差行均在入模内容中。通用组答出两组数值但省略误差单位。当前组把 38 °C 关联到错误区间，给出 0.2 °C。 |
| h07，比较 5 V 供电适用性 | 通用组的一次调用拿到两份供电范围，最后只输出引用编号。当前组分两次调用，分别收到 LM75B 的 2.8–5.5 V 和 MAX30205 的 2.7–3.3 V，最终也未给出 5 V 选型结论。两个原文范围放进同一次人工诊断后答对。 |
| h08，比较温度步长 | 原文的两个步长均已入库。通用组返回候选缺 MAX30205 的 0.00390625 °C/LSB，当前组缺 LM75B 的明确步长说明。给足两个数字后，LLM 仍把较小者说反，把正确的 32 倍算成 31.25 倍。 |
| h11，区分工作上限与绝对额定值 | MAX30205 正常工作上限 3.3 V 进入了上下文。原第 2 页的 +4 V 绝对额定值块 `a7bc38d8_p2_c5` 两组均排第 9，未进入上下文。额定值说明 `a7bc38d8_p2_c7` 已入库但未被召回。通用组拒答，当前组只解释了 3.3 V。 |

人工短证据诊断的 **核心结论正确 6/9**，同时满足完整答复和有效引用为 **4/9**。h02 的语义答对但添加了越界的 `[4]`。h11 的正常供电判断答对，但未引用，还加入了资料未支持的过压保护描述。h05 的正常 HTTP 回答正确，短证据诊断却把“完成本次转换后关断”改成“立即结束转换”。这个诊断同时改变了证据覆盖和冗余度，适合定位问题范围。 [人工短证据输入与模型答复](../data/eval/heldout/results/gold-context.jsonl) · [已索引原始块](../data/eval/heldout/results/indexed-chunks.json)

## 下一步优先级

1. 为多要点问题按所需事实组织证据，再分配上下文预算。用 h02 和 h11 回归不同来源块是否都入模，同时检查重复片段是否占用了位置。
2. 比较题先分别取证，再让同一次调用看到两边的带出处证据并给出结论。温度步长比值在单位校验后交给确定性计算。h07 和 h08 分别检查证据对齐与数字比较。
3. 用冻结的人工证据对照验证生成和引用。将本组作为诊断回归，下一轮再冻结另一组新器件。对照只覆盖两份温度传感器规格书的选页，独立验证范围仍需扩展。
